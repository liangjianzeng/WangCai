## §1 总纲：对齐什么、不对齐什么

**对齐（DSH 语义，WangCai 实现）**：
1. **日志即真相**：JSONL 事件源为会话唯一真相，LLM 消息与 UI 是派生物；SQLite 降级为索引（DSH `session-query` 角色）。
2. **一个数据家**：全部数据收进 `%APPDATA%\WangCai`（= `WangCaiPaths.dataRoot()`），对齐 DSH `~/.dsh` 单家纪律。
3. **cwd 绑定语义**：`SessionHeader.workspacePath/cwd` 是会话↔工作区的绑定凭据（DSH `SessionHeader.cwd` 模型）。
4. **桌面件**：窗口基本件（最小尺寸/几何记忆/单实例/真标题）、右键菜单、快捷键、composer 接管式审批、去 bottom-sheet。

**不对齐（明确不做，含原因）**：
- **Cordis/Node 插件体系**：WangCai 已有自有插件面（`lib/plugins/`：plugin_host/panel/builtin + host/*，已接线 `plugins_screen.dart`），不推倒。
- **settings.yaml 化**：SettingsService 百字段 JSON 先保留（Phase 5 仅评估），改造成本与收益不成比例。
- **多窗口 / 命令面板**：非本轮目标。
- **AWeb UI 三栏结构照抄**：WangCai rail 布局已成立，只补"面板几何记忆 + 常驻分栏"，不重写壳。

**顺序依赖**：Phase 1（数据家）→ Phase 2（JSONL 通电）必须先于 Phase 5.1（轨迹视图，读 JSONL）；Phase 3/4 与 1/2 无依赖可并行。

## §3 Phase 2 — JSONL 真相源通电（P0 核心，最高风险）

**目标**：对齐 DSH"日志即真相"。分两小步，每步独立可验收、可回退。

### 3.1 写入侧 write-through（2a）

回合管线把真实事件**追加**进 `JsonlSessionStore`（`appendEvent`，`store.dart:121`，append-only 落项目树——存储层已完全就绪）：

- **事件词表**：复用既有 `SessionEvent`（`event.dart:158`：`user/message`{kind:user}、`assistant/message`{kind:model}、`tool/call`、`tool/result`{kind:tool}、`turn/start|end`、`import`）。
- **写入点**：`chat_provider.dart` 回合管线——本轮已有事件流出口（`agentUiStateProvider.attach(conversationId, sessionLog)` 订阅同一 SessionLog，`:1592`），write-through 挂同一出口逐事件 `appendEvent`，**循环零侵入**（纪律同 metrics 派生）。
- **header 盖章**：回合首事件落盘前确保 header 写入——`_header()`（`store.dart:113`）已会从 `projectIdResolver → project.workspacePath` 派生 `workspacePath/cwd`，接线即生效。
- **失败语义**：JSONL 写失败**不阻塞回合**（debugPrint + 内存标记该会话 degraded），SQLite 照旧写——双写期 SQLite 永远兜底。

### 3.2 读取侧 fast path（2b）

`chat_provider.dart:1583-1589`（每回合 `importFromMessages` 重建）改为：

```
load(convId) 命中（文件存在且非空）→ 直接用 SessionLog
未命中 → importFromMessages（旧路）+ 一次性整体回写 JSONL（import 事件标记）
```

- 双读兜底纪律与 Phase 1 迁移一致：JSONL 损坏（解析 0 事件但文件非空）→ 回退 SQLite import 并记日志。
- `:2288/:2425` 两处上下文估算/压缩重建走同一 helper（抽 `_sessionLogFor(convId)` 私有方法，三处共用）。

### 3.3 真源验证（验收标准）

1. 发起回合 → `%APPDATA%\WangCai\projects/<pid>/sessions/<convId>.jsonl` 出现 header + 事件序列；杀进程重启 → 会话历史完整（读 JSONL fast path）。
2. **真相源证明**：手工删 SQLite `messages` 表一行 → 重启后该消息仍在（由 JSONL 派生）；反向删 JSONL 一行 → SQLite 还在（索引角色）。
3. 旧会话（无 JSONL）首回合自动整体回写，`import` 标记事件在文件头之后。
4. 崩溃修复：回合中 kill -9 → 重启 `closeOpenTurns(cause:'crash-repair')`（`store.dart:110`，已有）补齐。

### 3.4 测试

- `test/agent/session_write_through_test.dart`：写读回环、header cwd 盖章、损坏回退、幂等回写、删除联动（`ConversationsNotifier.delete` 已删 JSONL，`chat_provider.dart:241`，补断言）。

**风险**：双写不一致窗口（SQLite 成功 JSONL 失败）——接受，因读取侧 fast path 以"JSONL 存在且非空"为门槛，降级会话自动走 import 旧路，无死锁。**预估**：~5 文件 + 1 测试文件，是本轮唯一动回合管线的阶段。

## §7 红线复述（全程有效，违者停手）

1. **adb 不删**（用户明令，`lib/agent/adb/` 全保）。
2. `package:wangcai` 唯一包名；frozen prompt（`test/agent/frozen/`）改品牌文案必须同步字节一致。

7. 工具链/产物只放 E: 盘（MSVC 例外）。
